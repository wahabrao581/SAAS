Realtime WebSocket examples
===========================

Connect using a valid access token:

  ws://localhost:8000/realtime/?token=<ACCESS_TOKEN>

Use wss:// in production. The connection is authenticated when it opens.

Messages are JSON objects with an action and payload. The params field is
optional.

Create a project
----------------

Send:

{
  "action": "create_project",
  "payload": {
    "name": "Product launch video",
    "description": "A short launch video",
    "original_prompt": "Show the new product in use."
  }
}

Receive:

{
  "action": "create_project",
  "status": "success",
  "data": {
    "project": {
      "id": "<PROJECT_UUID>",
      "name": "Product launch video",
      "status": "draft"
    }
  }
}

The project ID is generated by the server; use the returned ID in later
requests.

Split a prompt into segments
----------------------------

Send (replace <PROJECT_UUID> with the ID returned above):

{
  "action": "split_prompt",
  "payload": {
    "project_id": "<PROJECT_UUID>",
    "prompt": "Open on the product in a bright studio.\n\nShow a close-up of its key feature.",
    "separator_mode": "blank_lines"
  }
}

Receive:

{
  "action": "split_prompt",
  "status": "success",
  "data": {
    "project_id": "<PROJECT_UUID>",
    "total_segments": 2,
    "segments": [
      {
        "id": "<SEGMENT_UUID_1>",
        "sequence": 1,
        "prompt": "Open on the product in a bright studio.",
        "title": null,
        "is_approved": false
      },
      {
        "id": "<SEGMENT_UUID_2>",
        "sequence": 2,
        "prompt": "Show a close-up of its key feature.",
        "title": null,
        "is_approved": false
      }
    ]
  }
}

Errors
------

Validation errors return an action and an errors array:

{
  "action": "create_project",
  "status": "error",
  "errors": [
    {
      "loc": ["name"],
      "msg": "String should have at least 2 characters",
      "type": "string_too_short"
    }
  ]
}

Permission or action errors return an action and a message:

{
  "action": "split_prompt",
  "status": "error",
  "message": "Permission denied for action 'split_prompt'"
}
